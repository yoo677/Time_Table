# Time Table

나만의 달력 + 타임테이블 웹앱. PC와 아이폰 브라우저에서 같이 쓴다.

## v1 기능

- 달력 화면: 월 단위 달력. 좌우 화살표나 좌우 스와이프로 달 이동, `오늘` 버튼
- 날짜를 누르면 그 칸이 커지면서 하루 화면이 열린다 (스프링 애니메이션)
- 하루 화면: 세로 시간표(00:00 ~ 24:00)
  - `+` 버튼으로 스택 추가: 이름, 걸리는 시간, 색상
  - 스택은 하루 시작 시각부터 순서대로 쌓이고, 걸리는 시간만큼 세로 길이가 정해진다
  - 하루 시작 시각은 상단 `시작`에서 바꾼다 (기본 08:00)
  - 스택을 누르면 이름·시간·색 수정, 위/아래로 순서 이동, 삭제
  - 좌우 화살표나 스와이프로 전날/다음날 이동
  - 오늘이면 현재 시각을 빨간 선으로 표시
- 다크 모드, 아이폰 홈 화면 추가(앱처럼 실행) 지원

키보드: `Esc` 닫기, `←` `→` 이동, 하루 화면에서 `N` 또는 `+` 로 스택 추가

## 저장 방식

v1은 데이터를 **이 기기의 브라우저(localStorage)** 에 저장한다. PC와 아이폰 사이 동기화는 아직 안 된다.
동기화는 다음 버전에서 Firebase를 붙여 해결할 예정이며, 저장 코드는 `store.js` 한 곳에 모아 두었다.

## 실행

빌드 과정 없는 정적 파일이다.

- 로컬: 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속
- 배포: GitHub 저장소 Settings → Pages → Deploy from a branch → 브랜치와 `/ (root)` 선택

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 (라이트/다크) |
| `app.js` | 달력, 하루 화면, 스택 시트, 애니메이션 |
| `store.js` | 데이터 저장 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설정 |
