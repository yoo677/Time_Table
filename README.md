# Time Table

나만의 달력 + 타임테이블 웹앱. PC와 아이폰 브라우저에서 같이 쓴다.

## 화면 구성

- **맨 위 줄.** 화면 폭 끝까지 이어지는 흰 띠. 왼쪽에 오늘 날짜(`YYYY/MM/DD (요일)`)와 초까지 가는 시계,
  오른쪽에 12시간 기온 그래프와 현재 날씨·기온·동네. 그래프는 지금·최고·최저 기온만 숫자로 적고, 마우스를 올리면 그 시각 값이 보인다.
  날씨는 위치 권한을 허용하면 그 자리 기준, 거절하면 서울 기준(`≈ 서울`)이다. 폰에서는 현재 날씨를 누르면 그래프가 펴진다.
- **왼쪽: 달력.** `‹ 2026년 10월 ›`로 달 이동, `오늘`로 이번 달과 오늘 칸으로 돌아간다(키보드 `T`). 좌우 스와이프도 된다.
  흐리게 보이는 앞뒤 달 날짜를 누르면 그 달로 밀려 넘어간다.
- **가운데 손잡이.** 끌어서 달력과 할 일의 폭을 나눈다. 두 번 누르면 기본 폭.
- **오른쪽: 할 일.** 세 묶음으로 나눈다.
  - `학교`: 학교 계정의 클래스룸과 Teams 과제
  - `학교 외`: 개인 계정의 클래스룸
  - `Tasks 내 할 일 목록`: 구글 Tasks와 이 기기에만 적은 할 일. `+`로 바로 추가한다(구글 개인 계정이 연결되어 있으면 Tasks에, 아니면 이 기기에 저장)
  - 묶음 제목을 누르면 접히고 펴진다. 접힌 묶음은 가장 급한 카드 뒤로 나머지가 겹친 더미로 보이고, 누르면 튕기듯 펴진다
  - 폰에서는 아래 탭으로 `캘린더`와 `할 일`을 오간다.

## 하루 시간표 창

날짜를 누르면 그 칸에서 창이 커져 나온다. 날짜마다 창이 따로 열려 여러 날을 나란히 볼 수 있다(최대 6개).
이미 열린 날짜를 누르면 그 창이 앞으로 온다.

- 제목 줄을 끌어 옮기고, 가장자리·모서리를 끌어 크기를 바꾼다(마지막 위치와 크기를 기억하고, 새 창은 조금씩 비켜 열린다)
- 오른쪽 위 `–` 최소화(아래쪽에 날짜 버튼으로 줄어든다, 누르면 복원), `×` 닫기. 제목 줄을 두 번 눌러도 최소화
- 왼쪽 위 `‹ ›`로 전날·다음날, `오늘`로 오늘

## 스택

- 빈 시간을 누르면 그 시각에, `+`를 누르면 마지막 스택 뒤에 새 스택을 만든다
- 시작 시각과 걸리는 시간은 아이폰 알람처럼 휠을 위아래로 굴려 정한다(마우스는 끌기·휠 스크롤)
- **옮기기:** PC는 바로 끌고, 폰은 길게 눌러 집어 든 뒤 끈다(그냥 밀면 스크롤)
- **크기:** 위·아래 손잡이로 시간, 왼쪽·오른쪽 손잡이로 가로 폭. 같은 시간대에 여러 스택을 나란히 둘 수 있다(멀티태스킹)
  - PC는 마우스를 올리면, 폰은 길게 눌러 선택하면 손잡이가 보인다
- 스택을 짧게 누르면 이름·시간·색 수정, 삭제

## 할 일을 시간표로

할 일 카드를 끌어다 놓으면 스택이 된다(PC는 바로 끌고, 폰은 길게 눌러 집어 든다).

- 열린 시간표 창 위에 놓으면 그 시각에 1시간짜리 자리가 미리 보이고, 놓으면 시트가 열린다
- 달력 칸에 놓으면 그 날짜 창이 열리고 시트가 뜬다(그날 마감인 과제면 마감 한 시간 전에 끝나게 잡는다)
- 시트에서 걸리는 시간과 색을 정해 `추가`한다. 이름은 할 일 제목, 색은 출처 색으로 미리 채워진다
- 폰에서 끄는 중에 아래 `캘린더` 탭이나 최소화된 창 버튼 위에 잠깐 머물면 그쪽이 열린다

키보드: `Esc` 맨 앞 창 닫기, `←` `→` 맨 앞 창 날짜 이동, `N`/`+` 새 스택, `T` 오늘

## 저장 방식

데이터는 **이 기기의 브라우저(localStorage)** 에 저장한다. 기기 간 동기화는 아직 없다. 저장 코드는 `store.js`에 모아 두었다.

## 외부 연동

조사 결과와 준비 절차는 [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md)에 있다.

## 실행

빌드 과정 없는 정적 파일이다.

- 로컬: 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속 (`?demo`를 붙이면 예시 데이터)
- 배포: GitHub 저장소 Settings → Pages → Deploy from a branch → 브랜치와 `/ (root)` 선택

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인 (라이트/다크) |
| `app.js` | 맨 위 줄, 달력, 할 일 묶음, 시간표 창(여러 개), 스택 끌기, 할 일 끌어 넣기, 휠 피커 |
| `weather.js` | 위치, 날씨(Open-Meteo), 지명(BigDataCloud) |
| `store.js` | 스택 저장, 화면 설정 저장 |
| `config.js` | 구글·Microsoft 클라이언트 ID |
| `google.js` | 구글 로그인, 클래스룸·Tasks 불러오기 |
| `microsoft.js`, `auth.html` | Microsoft 로그인, Teams 과제 불러오기 |
| `sources.js` | 외부 연동 항목(마감) 보관, 이 기기 할 일, 예시 데이터 |
| `docs/INTEGRATIONS.md` | 연동 조사·준비 절차 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설정 |
